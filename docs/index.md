## Documentation Map

- [Paper Plan](paper_plan.md): current research questions, body/tail design,
  robust-satisficing gates, shared-date inference and manuscript structure.
- [Data](data.md): source roles, target hierarchy, point-in-time controls, and data-source
  limitations.
- [Results Snapshot](results_snapshot.md): current frozen-forecast results,

- [FAQ](faq.md): short reader-facing framing for the research

## Reading Order

1. Start with the [Paper Plan](paper_plan.md) for the current design and evaluation rules.
2. Read [Data](data.md) for the target, sources, and point-in-time controls.
3. Use the [Results Snapshot](results_snapshot.md) to inspect the current evidence.
4. Use the [FAQ](faq.md) for the plain research framing.
5. Use [Future Work](future_work.md) to keep deferred extensions out of the current paper.
